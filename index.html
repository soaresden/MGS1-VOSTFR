1Balance tes jeux

Tes disques PAL, en CHD (comme dans Batocera) ou en BIN : la version française, la version européenne (anglaise), ou les deux. Tout d'un coup.

Les deux versions sont nécessaires pour la VOSTFR ; une seule suffit pour les mods.

    Bon à savoir
    
    
    
      Comment jouer ensuite ?
      
    
        
    Tu obtiens Metal Gear Solid (…) (Disc 1).bin/.cue, (Disc 2) et un .m3u. Ouvre le .m3u dans ton émulateur (Batocera, DuckStation…) : il pourra changer de disque. Avec le CD Combiner, ouvre plutôt (1 CD).cue : tout le jeu, sans changement de disque.
    
        
    Avec une nouvelle version des images, reprends ta partie depuis une sauvegarde de la carte mémoire, pas depuis une sauvegarde d'état de l'émulateur (elle garde l'ancienne version).

      Comment ça marche ?
      
    
        
    
          Cinématiques VOSTFR : les deux versions PAL ont exactement les mêmes blocs audio, le son anglais est donc recopié dans les cinématiques françaises, sous les sous-titres français.
    
        
    
          Codec et voix en jeu VOSTFR : les quelque 1 100 banques de voix de chaque disque sont appariées à leur équivalent français ; la voix anglaise passe et le texte français la suit réplique par réplique. L'image du disque est reconstruite (les voix anglaises prennent plus de place).
    
        
    
          Mods : de petits morceaux de code MIPS ajoutés à l'exécutable du jeu, après vérification des octets d'origine.
    
        
    Cette page fait la même fabrication que les scripts Python du projet, réécrite en JavaScript : les images sont identiques, octet pour octet. Les détails sont sur GitHub.
    
      
    
    
    
    
    
      En ligne de commande (Python)
      
    
        
    Même résultat avec Python 3.10+ et numpy ; chaque option est un argument. --vf : jeu français + mods ; --vo : jeu anglais + mods.
    
        
    git clone https://github.com/soaresden/MGS1-VOSTFR
cd MGS1-VOSTFR/tools
pip install numpy
python build.py --carre --m9 --psg1 --l2r2 --fps \
  --fr1 "MGS (France) (Disc 1).chd" --uk1 "MGS (Europe) (Disc 1).chd" \
  --fr2 "MGS (France) (Disc 2).chd" --uk2 "MGS (Europe) (Disc 2).chd" \
  --out ../work/out
